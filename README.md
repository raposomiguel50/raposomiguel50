## System Shock — Android

An unofficial Android/ARM64 port based on [Shockolate](https://github.com/Interrupt/systemshock), tested on the Retroid Pocket 5.

Version 1.0.0 includes handheld controls, optional touch input, Android text entry and a first-run game-data importer. The game uses a 1024×768, 4:3 presentation without stretching.

**The APK is available.** Supply compatible data from your own copy of System Shock.

[Project and installation](https://raposomiguel50.github.io/projects/system-shock-android/) · [Download v1.0.0](https://github.com/raposomiguel50/system-shock-android/releases/tag/v1.0.0) · [Source](https://github.com/raposomiguel50/system-shock-android)

## The Legend of Zelda: The Minish Cap — RG34XX

An unofficial native port for the GBA-style RG34XX handheld with muOS. It builds on [EstebanPdN's Project Picori-derived source](https://github.com/EstebanPdN/zelda-tmc-3ds).

The reference uses integer-scaled imagery and keeps port settings separate from gameplay. The aim is to preserve the existing game.

**Integration source and guides are available.** There is no public game executable. No proprietary game assets are included.

[Explore the project](https://raposomiguel50.github.io/projects/minish-cap-rg34xx/) · [Engineering lessons](https://raposomiguel50.github.io/projects/minish-cap-rg34xx/knowledge/) · [Source](https://github.com/raposomiguel50/minish-cap-rg34xx)
